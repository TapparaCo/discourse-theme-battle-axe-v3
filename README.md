# Battle Axe v3

Discourse theme for [Tappara.co](https://tappara.co).

## Color schemes

- **Home Colors**: dark navy background with an orange header
- **Away Colors**: light background with a blue header
- **Axe Nord**: dark scheme with Nord-inspired pastel colors

## Features

- Topic list on desktop with a category column and a latest post column showing the last poster's avatar, name and time
- Minor UI tweaks

## Theme components

These components are installed separately and added to this theme:

- [Google Consent Settings](https://github.com/TapparaCo/discourse-google-consent-settings): hides Google's floating consent toolbar and adds a "Privacy and cookie settings" link to the user menu and sidebar

## Installation

Admin → Customize → Themes → Install → From a git repository: `https://github.com/TapparaCo/discourse-theme-battle-axe-v3`
